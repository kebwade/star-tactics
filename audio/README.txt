背景音乐放这里（audio/）
========================================

  audio/bgm.m4a     整个游戏的背景音乐（循环播放）

★ 文件名固定，被 js/ui.js 里的 BGM_SRC 直接引用：

     var BGM_SRC = 'audio/bgm.m4a';

  想换音乐：直接把新文件覆盖成这个名字就行，代码一个字都不用动。
  换成 mp3 / ogg 也可以，只要把 ui.js 里那一行的扩展名一起改掉。

现在这首是怎么来的（可复现）
----------------------------------------
user 提供的视频（微信保存的 mp4，HEVC 画面 + AAC 音轨，约 15.7 秒），
用 Windows 自带的 Media Foundation 走三步做出来的（机器上没有 ffmpeg）：

  powershell -NoProfile -ExecutionPolicy Bypass -File tools\_make-bgm.ps1 ^
      -In "原始视频.mp4" -Out "audio\bgm.m4a"

  ① 解码成 WAV（Media Foundation，系统自带，零安装）
  ② 掐掉头尾的静音 + **交叉淡化拼接**（下面细说）
  ③ 编码回 AAC/m4a（48kHz / 160kbps）

  本次结果：头掐掉 385ms、尾 3ms，交叉淡化 600ms，
            15.70s → **14.71s**，298 KB，纯音频（没有任何视频轨）。

为什么"直接 loop"不行、交叉淡化是怎么做的
----------------------------------------
  · 头尾带静音 → 每循环一圈就有一小段空白（这次是开头 385ms，很明显）。
  · 结尾和开头波形接不上 → 每圈"啪"一声（爆音）。

  做法：把结尾 F 秒和开头 F 秒叠在一起（F = 0.6s），拼成的新循环里
  第一段 = 开头淡入 + 尾巴淡出。这样"循环点"两侧的素材**本来就是连续的**
  （数学上就是原素材里的相邻两点），所以既没有空白也没有爆音。
  脚本会打印接缝跳变值做校验，本次是 0.0001（素材内部平均是 0.011，
  也就是接缝处的跳变比素材自己相邻两点的跳变还小 100 倍，听不出来）。

播放上的几个约定（都在 js/ui.js 里写着注释）
----------------------------------------
  · **进封面就开始放**（game.js 在 boot 里调 UI.sound.autoMusic）。
  · 浏览器不许自动播放有声媒体，所以是三保险：
    进页面先试一次 → 任何一次点击/按键/切回前台再试 → 音频解码就绪时再试。
    （原来只挂了一个一次性的 pointerdown，那一次点击往往正撞上"还没解码完"，
       play() 被拒之后就再也不试了 —— 这就是"开始界面没有音乐"的原因。）
  · **不用 WebAudio 接播放器**：本作是双击 index.html 用 file:// 打开的，
    file:// 下的媒体会被当成跨域，接进 createMediaElementSource 会直接静音。
    所以直接播 `<audio loop>`，音量用 el.volume。
  · 音乐音量 = 总音量 × 音乐音量 × 2（默认 0.75 × 0.30 → 0.45），
    在「设置 → 背景音乐」里调，拉到 0 就是静音。
  · 文件读不出来（被删了 / 浏览器不支持 AAC）会自动退回原来那段
    现场合成的五声音阶琶音，不会变成"点了没反应"。

tools/ 里几个和音频有关的小工具
----------------------------------------
  _make-bgm.ps1      视频/音频 → 无缝循环的 bgm.m4a（就是上面那条命令）
  _extract-audio.ps1 只抽音轨、不做循环处理（想自己剪的时候用）
  _probe-mp4.ps1     打印 mp4/m4a 的盒子树、时长、码率、chunk 偏移是否越界
